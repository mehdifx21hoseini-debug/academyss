# کد سیستم MENTORAI

این پوشه عمداً خالی است.

هیچ فایلی اینجا ساخته نمی‌شود تا وقتی معماری انتخاب و تأیید شود. چیدمان پوشه‌ها خودش
یک تصمیم فنی است: اینکه سمت سرور با چه زبانی نوشته شود، پنل مدیریت جدا باشد یا نه،
و هر بخش کجا قرار بگیرد. ساختن پوشه‌های الکی الان یعنی گرفتن آن تصمیم‌ها بدون تأیید.

پرسش‌هایی که باید جواب بگیرند تا کار اینجا شروع شود:

1. زبان و چارچوب سمت سرور
2. پایگاه داده و روش جستجوی معنایی روی محتوای فارسی
3. روش اتصال به تلگرام: ربات رسمی یا حساب کاربری
4. بستر پنل مدیریت
5. محل استقرار و روش انتشار
