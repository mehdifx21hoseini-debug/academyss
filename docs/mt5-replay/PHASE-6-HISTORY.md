## Cache در برابر Window — تفاوتی که در Phase 2 وعده داده شد

| | Bar Window (P2) | Seed Cache (اینجا) |
|---|---|---|
| کجا | حافظه | دیسک |
| عمر | با جلسه می‌میرد | بین ری‌استارت‌ها می‌ماند |
| چه چیزی را نجات می‌دهد | `CopyRates` در هر Pump | **نوشتن Warmup** |

دانلود دوباره گران نیست — MetaTrader تاریخچه بروکر را خودش روی دیسک نگه می‌دارد. گران، **هل دادن صدهزار کندل به داخل Custom Symbol** است. Cache دقیقاً همان را حذف می‌کند.

**هرگز به خودش اعتماد کور نمی‌کند:** Manifest یک ادعاست؛ کندل‌ها مدرک‌اند. قبل از پذیرش، خود نماد بررسی می‌شود که واقعاً آن کندل‌ها را دارد.

## نقل قیمت قبل از پرداخت

حساب سند طراحی، اجراشدنی شد:

```
۲۰۰ کندل D1  →  ۲۸۸٬۰۰۰ کندل M1
```

کاربری که «Context روزانه» انتخاب می‌کند و بعد چهار دقیقه بدون توضیح منتظر می‌ماند، نتیجه می‌گیرد ابزار خراب است. **همان انتظار، اگر اول اعلام و پذیرفته شود، فقط یک بارگذاری است.**

دیالوگ با هر تغییر، تخمین را دوباره حساب می‌کند و دکمه START بازه‌ای را که بروکر نمی‌تواند سرو کند رد می‌کند.

نرخ Seed فعلاً یک **حدس مستند** است (`6000 bars/s`). به‌محض اجرای Spike D1، `SetMeasuredSeedRate()` آن را با عدد واقعی جایگزین می‌کند و نقل قیمت از تخمین به واقعیت تبدیل می‌شود.

## Code Review — دو باگ واقعی

### 🐞 Cache هیچ صرفه‌جویی نمی‌کرد — Critical

روی Reuse، Sink **نوشتن** را رد می‌کرد. اما کنترلر از قبل تمام کندل‌های Warmup را از لایه داده **خوانده بود** تا تحویلش دهد.

برای Warmup صدهزار کندلی، آن خواندن بیشترِ هزینه است. یعنی **Cache نیمه‌ی ارزان را نجات می‌داد و نیمه‌ی گران را همچنان می‌پرداخت.**

**اصلاح:** یک پرسش عمومی، نه Cache-شکل:

```
virtual bool NeedsWarmup(from, to) { return true; }
```

Core از Sink می‌پرسد اصلاً Warmup لازم دارد یا نه — و **هرگز نمی‌فهمد چرا نه**. Sinkای که کندل‌ها را دارد «نه» می‌گوید و خواندن اصلاً اتفاق نمی‌افتد.

### 🐞 محاسبه‌ی گپ سشن، چیزی که ادعا می‌کرد را حساب نمی‌کرد — High

تابع اول:
- گپ‌های روز کامل را **جمع** می‌کرد به‌جای بیشینه‌گیری
- هر Open سشن را **از نیمه‌شب** می‌سنجید، نه از Close سشن قبلی

نتیجه: نمادی که ۲۴/۵ معامله می‌شود حدود یک ساعت گزارش می‌داد، در حالی که گپ واقعی آخر هفته **دو روز** است.

**اصلاح:** همه سشن‌های هفته روی یک Timeline جمع می‌شوند، گپ از **Close تا Open بعدی** سنجیده می‌شود، و Wrap آخر هفته (جمعه→دوشنبه) هم حساب می‌شود.

### 🔧 اصلاح لایه‌بندی

`SSR_SeedCache` در `Data/` بود ولی چیزی که توصیف می‌کند **داخل Custom Symbol** است — کار Adapter، نه لایه داده. منتقل شد به `Mt5/`، و وابستگی `Mt5 → Data` حذف شد.
