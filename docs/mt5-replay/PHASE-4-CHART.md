## Auto-Scroll — چرا این یک قابلیت واقعی است

Auto-Scroll خود MetaTrader با هر تیک، نما را به آخرین کندل می‌کشد. در Replay این ده‌ها بار در ثانیه است، پس کاربری که می‌خواهد قیمت قبلی را ببیند **مدام به جلو پرت می‌شود** و ابزار خراب حس می‌شود.

راه‌حل: تشخیص اسکرول دستی → رها کردن Auto-Scroll → دکمه‌ی صریح برای بازگشت.

### معیار تشخیص

```
offset = CHART_FIRST_VISIBLE_BAR − (CHART_VISIBLE_BARS − 1)
```

MT5 کندل‌ها را از راست ایندکس می‌کند، پس در لبه‌ی راست چپ‌ترین کندل مرئی `visible−1` است. هر مقدار بزرگ‌تر یعنی فاصله از انتها — و این چه از کشیدن کاربر بیاید چه از رسیدن کندل جدید در حالی که نما ثابت مانده، **درست است**. یک عدد هر دو را پوشش می‌دهد.

## Code Review — دو مشکل واقعی

### 🐞 تشخیص کاذب اسکرول (High)

یک نوشتن انبوه — مثلاً Seek رو به جلو که صد کندل یکجا می‌ریزد — می‌تواند offset را برای یک لحظه، پیش از بازترسیم MetaTrader، از آستانه رد کند.

**یک نمونه‌برداری این را «کاربر اسکرول کرد» می‌خواند و بی‌صدا دنبال‌کردن را روی چارتی که کسی لمسش نکرده متوقف می‌کند.**

**اصلاح:** Detach حالا نیازمند **دو Sync متوالی** بالای آستانه است. هزینه: یک تیک تایمر. حذف کل این دسته از False Positive.

### 🐞 چارت خارج از سقف رجیستری، بی‌صدا نادیده گرفته می‌شد (Medium)

بالای `SSR_MAX_CHARTS`، چارت جدید فقط رد می‌شد. اما آن چارت همچنان به کاربر داده نشان می‌دهد — فقط سیاست Follow نمی‌گیرد. حالا شمرده و گزارش می‌شود.

### 🔧 اصلاح لایه‌بندی

`SSR_SymbolNaming` در `Mt5/` بود ولی **هیچ API متاتریدری ندارد** — منطق رشته‌ی خالص. باعث می‌شد `Chart → Mt5` یک وابستگی عرضی داشته باشد فقط برای شناختن یک نام.

منتقل شد به `Common/`. لایه‌بندی حالا کاملاً یک‌طرفه:

```
Core   → Common
Data   → Common, Core
Mt5    → Common, Core
Chart  → Common
```

## Leak Guard — صداقتی که در کد قابل اجرا نیست

موتور تضمین می‌کند **نماد Replay** داده آینده ندارد. نمی‌تواند تضمین کند کاربر در پنجره‌ی بغلی به نماد واقعی نگاه نمی‌کند.

این شکاف در کد بستنی نیست — MetaTrader اجازه نمی‌دهد یک برنامه چارت دیگری را ممنوع کند. پس پاسخ صادقانه **تشخیص و اعلام بلند** است، هر جلسه.

| نشت | تشخیص | اقدام |
|---|---|---|
| نماد مبدأ در Market Watch | `SYMBOL_SELECT` | پیشنهاد حذف — **هرگز خودکار** |
| چارت باز روی نماد مبدأ | پیمایش چارت‌ها | هشدار؛ چارت کاربر بسته نمی‌شود |
| سایر نمادهای زنده | پیمایش چارت‌ها | شمارش اطلاعاتی |

`HideOrigin()` وجود دارد اما پنل باید **بپرسد**. مخفی کردن نمادی که کاربر خودش گذاشته، همان نوع کمکِ ناخواسته‌ای است که اعتماد را از بین می‌برد.

همین منطق در بستن چارت: `CloseOwned()` **فقط چارت‌هایی را می‌بندد که خودمان باز کرده‌ایم**.

## تست کلیدی — کندل نیمه‌کامل HTF

`T4.3` چیزی را می‌سنجد که ابزارهای دیگر خراب می‌کنند:

```
در زمان T، کندل جاری H1 باید:
  ✓ در T یا قبل از آن باز شده باشد
  ✓ هنوز بسته نشده باشد
  ✓ High/Low اش دقیقاً برابر M1های تا این لحظه باشد
```

ابزاری که وسط ساعت یک کندل H1 کامل نشان می‌دهد، دارد آینده نشان می‌دهد.
