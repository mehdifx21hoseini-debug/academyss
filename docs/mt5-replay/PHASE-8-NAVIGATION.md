## چرا Rewind به Snapshot نیاز دارد و Seek ساده کافی نیست

Seek رو به عقب از قبل Sink را درست Truncate می‌کند. پس یک لحظه به‌نظر می‌رسد Snapshot تشریفات است. **نیست** — و دلیلش امروز قابل مشاهده است:

```
RewindTo(msc) {
   emitted_msc = msc - 1;
   tick_count  = 0;      ← اینجا
   bar_count   = 0;      ← و اینجا
}
```

Rewind، Cursor را ریست می‌کند و Cursor شمارنده‌های جلسه را حمل می‌کند. با Seek ساده، **کاربری که یک کندل به عقب برمی‌گردد، آمار کل جلسه‌اش را از دست می‌دهد** — شمارنده از صفر شروع می‌شود، نه به مقدار آن لحظه برمی‌گردد.

و به‌محض اینکه Phase 9 یک حساب مجازی پشت همان Cursor بگذارد، این از یک عدد اشتباهِ ظاهری تبدیل می‌شود به **معاملاتی که در آینده‌ای اتفاق افتاده‌اند که دیگر وجود ندارد**.

> **State را بازیابی کن، بازسازی نکن.**

Checkpointها خودکار و بر اساس **زمان Replay** گرفته می‌شوند (هر ۵ دقیقه). یعنی یک گام به عقب حداکثر ۵ دقیقه بازپخش می‌خواهد، نه کل جلسه.

وقتی Checkpointی آنقدر عقب نمی‌رسد، به Seek ساده برمی‌گردد — **و گزارش می‌دهد**، نه اینکه معادل جا بزند.

## Jump: میراث Phase 7

حساب Phase 7 نشان داد ۵۰x یک روز معامله را در **۲۹ دقیقه** پخش می‌کند. پس پوشش دادن مسافت با تزریق تیک، پوشش دادن مسافت نیست.

```
JumpForward(target):
   کندل‌های قبل از کندلِ هدف  →  SeedBars()  (Bulk، بدون پخش چارتی)
   کندلِ حاوی هدف            →  تیک، بریده تا هدف
```

**کندل حاوی هدف عمداً از Bulk کنار گذاشته می‌شود.** نوشتن کاملش یعنی گذاشتن باقی آن دقیقه — یعنی آینده — داخل چارت.

تست `T8.4` می‌سنجد که ده ساعت بازار **به‌صورت کندل** برود نه تیک.

## Code Review — دو باگ واقعی

### 🐞 Bookmarkها با Restart پاک می‌شدند — Medium

`Reset()` هم Checkpointها را پاک می‌کرد هم Bookmarkها.

اما **Checkpoint مالِ ماست، Bookmark مالِ کاربر** — لحظه‌ای که خودش انتخاب کرده برگردد. Restart داخل همان جلسه است؛ دور انداختن یادداشت‌های کاربر همراه با ماشین‌آلات پخش، اشتباه است.

**اصلاح:** `ClearCheckpoints()` جدا از `Clear()`. فقط شروع یک جلسه‌ی واقعاً جدید Bookmarkها را پاک می‌کند.

### 🐞 Jump قبل از Load، روی مقدار بی‌معنی می‌نشست — Medium

`JumpForward` سیم‌کشی را چک می‌کرد ولی **وضعیت را نه**. پرش قبل از `Load` روی یک Timeline مقداردهی‌نشده Clamp می‌شد و ساعت روی چیزی بی‌معنی می‌نشست — به‌جای گزارش مشکل واقعی.
