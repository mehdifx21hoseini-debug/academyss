# راه‌اندازی آزمایشی یک‌هفته‌ای

سیستم اول روی **یک** حساب بالا می‌آید و یک هفته کار می‌کند. هدف این هفته گرفتن باگ و
دیدن اعداد واقعی است، نه اثبات چیزی. وصل کردن دو حساب دیگر بعد از دیدن این اعداد و با
تأیید صریح مالک انجام می‌شود. تصمیم و شرط عبور در `ADR-018` ثبت شده است.

در این هفته سیستم در **حالت پیش‌نویس** کار می‌کند: دستیار جواب را می‌سازد، منتور در
ربات کنترل می‌بیند و با یک لمس تأیید می‌کند، و پیام از حساب خود منتور می‌رود. هیچ
پاسخ تأییدنشده‌ای به دانشجوی واقعی نمی‌رسد. تغییر به ارسال خودکار یک مقدار در پایگاه
داده است و تغییر کد لازم ندارد (ADR-006).

## آنچه پیش از روز اول لازم است

| # | چه چیزی | چرا |
|---|---|---|
| ۱ | یک سرور با HTTPS و پشتیبان‌گیری | پنل روی اتصال رمزنگاری‌نشده اصلاً کار نمی‌کند |
| ۲ | `api_id` و `api_hash` از my.telegram.org | برای همان یک حساب |
| ۳ | دسترسی به حساب منتور برای ورود دستی | ورود تعاملی است و خودکار نمی‌شود |
| ۴ | توکن ربات کنترل از BotFather | بدون آن منتور پیش‌نویس نمی‌بیند |
| ۵ | شناسه‌ی عددی تلگرام منتور و مالک | فهرست سفید `CONTROL_OPERATOR_IDS` |
| ۶ | فهرست کسانی که دانشجو نیستند | تا از پردازش استثنا شوند |
| ۷ | کلید Anthropic | برای مدل گفتگو |

⚠️ `CONTROL_OPERATOR_IDS` را حتماً پر کنید. فهرست سفید است و خالی بودنش یعنی هیچ‌کس
اجازه ندارد — که امن است. ولی اگر اشتباه پر شود، هر کسی که ربات را پیدا کند می‌تواند
گفتگوی خودش را به حساب وصل کند، پیام‌های واقعی دانشجوها را ببیند و از طرف منتور پاسخ
بفرستد.

## راه‌اندازی

```bash
cd mentorai
cp .env.example .env            # مقادیر واقعی را پر کنید
docker compose up -d db
docker compose run --rm gateway python -m alembic upgrade head
```

پایگاه دانش را وارد کنید. فایل خروجی بیرون از تصویر داکر است، پس باید سوار شود:

```bash
docker compose run --rm -v "$PWD/../exports/core:/kb:ro" gateway \
    mentorai kb-import --file /kb/mentorai_kb_latest.csv
```

انتظار: `ساخته شد: 641`.

حساب را ثبت و وارد کنید. ورود عمداً دستی است؛ ورود مکرر خودش برای تلگرام سیگنال
منفی است:

```bash
docker compose run --rm gateway mentorai add-account \
    --slug mentor-a --mentor-name "نام منتور" --phone "+98..."
docker compose run --rm -it gateway mentorai login --slug mentor-a
```

کسانی را که دانشجو نیستند استثنا کنید، **پیش از** بالا آوردن دروازه:

```bash
docker compose run --rm gateway mentorai exclude-chat \
    --slug mentor-a --peer-id 123456789 --reason "همکار"
```

حالا سیستم را بالا بیاورید:

```bash
docker compose up -d gateway worker
```

کارگر اختیاری نیست. بدون آن دروازه پیام را می‌گیرد و در صف می‌گذارد و همان‌جا می‌ماند:
نه پیش‌نویسی ساخته می‌شود و نه ربات کنترل بالا می‌آید.

پنل را بسازید و پشت HTTPS بگذارید:

```bash
docker compose run --rm -it gateway mentorai panel-user \
    --username mentor_a --display-name "نام منتور" --role mentor --slug mentor-a
docker compose run --rm -it gateway mentorai panel-user \
    --username boss --display-name "مدیر" --role admin
docker compose up -d panel
```

سرویس پنل فقط روی `127.0.0.1:8000` باز می‌شود. یک پروکسی با گواهی معتبر جلویش
بگذارید؛ کوکی نشست علامت `secure` دارد و روی HTTP اصلاً ذخیره نمی‌شود.

## هر روز چه چیزی را ببینیم

پنل جایی است که می‌شود دید دستیار جواب داد یا نداد و **چرا**. در تلگرام این دیده
نمی‌شود، چون سکوت هیچ اثری نمی‌گذارد.

سه عدد را جدا بشمارید:

- **پاسخ داده** — پیش‌نویس ساخته شد. اینکه منتور چقدر بازنویسی کرده مهم‌ترین سنجه‌ی
  کیفیت است.
- **ساکت با دلیل قاعده‌ای** (`rule_money`, `rule_complaint`, `rule_account`,
  `rule_explicit_human_request`) — این‌ها طبق طراحی همیشه انسانی‌اند. عدد بالا اینجا
  نشانه‌ی خرابی نیست.
- **ساکت با دلیل کیفیت** (`no_sources`, `low_confidence`, `model_flagged`) — این‌ها
  فهرست کاری هفته‌ی بعدِ پایگاه دانش‌اند.

`unsupported_media` را جدا بشمارید. آن محدودیت توانایی است نه شکست پاسخ‌گویی (ADR-017)،
و همین شمارش است که می‌گوید ساخت کدام گام از `docs/MEDIA.md` اول می‌ارزد: اگر بیشترِ
فایل‌ها ویس بود گام ۱، اگر استیتمنت بود گام ۲.

## چیزهایی که از قبل می‌دانیم و نباید باگ حساب شوند

- **جست‌وجوی معنایی هنوز روشن نیست.** بازیابی فقط متنی است (ADR-019). سؤالی که با
  واژه‌های دیگری پرسیده شده پیدا نمی‌شود و به ارجاع می‌رسد. عدد اندازه‌گیری‌شده:
  `recall@5` برابر ۰٫۴۰ روی ۸۰۷ پرسش ارزیابی.
- **پرسش کوتاهِ دنباله‌دار بازیابی نمی‌شود.** بازیابی فقط متن همان پیام را می‌بیند، نه
  مکالمه را. «خطرناکه؟» به‌تنهایی هیچ سند درستی ندارد و باید هم ساکت بماند.
- **پیام دارای فایل پاسخ نمی‌گیرد** و به منتور می‌رود.
- **هیچ پیامی آغاز نمی‌شود.** سیستم فقط پاسخ می‌دهد؛ ارسال آغازین، ارسال گروهی و
  افزودن مخاطب ممنوع دائمی‌اند (`docs/TELEGRAM_SAFETY.md`).

## اگر چیزی خراب شد

```bash
mentorai pause --slug mentor-a --reason "بررسی"     # قطع فوری ارسال
mentorai pause --slug mentor-a --resume
```

حساب‌ها مستقل‌اند؛ توقف یکی بقیه را متوقف نمی‌کند. اگر تلگرام هشدار محدودیت داد، فوراً
متوقف کنید و تا روشن شدن علت ادامه ندهید — اعتبار حساب گران‌ترین دارایی این سیستم است.

## شرط عبور به سه حساب

طبق `ADR-018`: حداقل ۱۰۰ پیام دانشجو پردازش‌شده، بازنویسی کامل پیش‌نویس زیر ۱۰٪، هیچ
هشدار محدودیت از تلگرام، و هیچ خطای ثبت‌نشده. زیر این شرط، هفته تمدید می‌شود.
