# 🎙️ آکادمی سبحان صمدی — پلتفرم آموزشی

وب اپلیکیشن تخصصی برای پادکست‌ها، کتاب‌های صوتی و منتورینگ آکادمی سبحان صمدی

---

## 🚀 راه‌اندازی سریع

### ۱. ساختار پوشه‌ها

```
sobhan-academy/
├── index.html          ← صفحه اصلی
├── admin.html          ← پنل مدیریت
├── assets/
│   ├── logo.png        ← لوگوی آکادمی
│   ├── sobhan.webp     ← عکس سبحان صمدی
│   └── audio/          ← فایل‌های صوتی را اینجا بگذارید
├── css/
│   ├── style.css       ← استایل اصلی
│   └── admin.css       ← استایل پنل مدیریت
└── js/
    ├── data.js         ← داده‌های پادکست و کتاب
    ├── player.js       ← موتور پلیر صوتی
    ├── app.js          ← منطق صفحه اصلی
    └── admin.js        ← منطق پنل مدیریت
```

### ۲. اضافه کردن فایل صوتی

1. فایل‌های MP3/M4A/WAV خود را در پوشه `assets/audio/` قرار دهید
2. وارد پنل مدیریت شوید: `admin.html`
3. پادکست یا کتاب را ویرایش کنید
4. مسیر فایل را وارد کنید: `assets/audio/podcast1.mp3`

### ۳. ورود به پنل مدیریت

- آدرس: `admin.html`
- نام کاربری: `admin`
- رمز عبور: `sobhan1404`

> ⚠️ حتماً بعد از اولین ورود، رمز عبور را از تب «تنظیمات» تغییر دهید!

## 🌐 استقرار روی GitHub Pages

1. یک مخزن جدید در GitHub بسازید
2. تمام فایل‌ها را Push کنید
3. به Settings → Pages بروید
4. منبع را `main branch` / `root` قرار دهید
5. سایت در آدرس `https://username.github.io/repository-name` فعال می‌شود

## 🔧 سفارشی‌سازی

برای تغییر محتوای اولیه، فایل `js/data.js` را ویرایش کنید:

```javascript
window.SSAData = {
  podcasts: [
    {
      id: 'p1',
      title: 'نام پادکست',
      description: 'توضیحات',
      author: 'سبحان صمدی',
      category: 'trading', // trading | psychology | analysis
      duration: '۴۵:۳۰',
      views: '۱۲K',
      emoji: '🎙️',
      src: 'assets/audio/file.mp3'
    }
  ]
}
```
