# MENTORAI

سامانه منتورینگ هوشمند آکادمی سبحان صمدی.

دانشجو در تلگرام سؤال می‌پرسد، هوش مصنوعی پاسخ می‌دهد، و هر جا اطمینان کافی نباشد
مکالمه به منتور انسانی سپرده می‌شود. یک پنل مدیریت هم مکالمه‌ها، دانشجوها، منتورها،
منبع دانش و شاخص‌ها را نشان می‌دهد.

## ساختار مخزن

| مسیر | محتوا |
|---|---|
| `mentorai/` | کد سیستم اصلی. راهنمای اجرا و توسعه در `mentorai/README.md`. |
| `docs/` | مستندات پروژه و ثبت تصمیم‌های معماری. |
| `.claude/` | راهنماهای پروژه برای دستیار کدنویسی و تنظیمات بازبینی امنیتی. |
| `legacy-site/` | سایت قبلی پادکست و کتاب صوتی. بایگانی، بخشی از سیستم جدید نیست. |

## وضعیت فعلی

معماری تصویب شده و کد نوشته می‌شود. مرحله‌های ۰ تا ۶ و مرحله‌ی ۹ (پنل مدیریت)
پیاده‌سازی شده‌اند: دریافت پیام از تلگرام، پایگاه دانش و بازیابی ترکیبی، لایه‌ی تصمیم،
ارجاع به منتور، حافظه‌ی دانشجو، و پنل وب.

مرحله‌های ۷ و ۸ — تنظیم دقیق کیفیت پاسخ و آماده‌سازی برای بار واقعی — به داده‌ی محیط
تولید نیاز دارند و پیش از استقرار معنی ندارند.

روند تصمیم‌گیری و مواردی که بدون تأیید مالک انجام نمی‌شوند در
`.claude/skills/mentorai-architecture/SKILL.md` آمده است.

## مستندات

- `docs/ARCHITECTURE_DECISIONS.md` — هر تصمیم معماری با دلیل، جایگزین‌ها و هزینه‌اش
