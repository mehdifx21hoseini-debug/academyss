# لایه‌ی دانش بروکر

## وضعیت فعلی
هیچ بروکری برای آکادمی مشخص نشده و هیچ مستند رسمی‌ای دریافت نشده است. (مورد `RQ-0004`)
تا آن زمان، این پوشه عمداً خالی از رکورد دانش است.

## چرا این لایه جداست
شرایط بروکر (اسپرد، کمیسیون، سواپ، اهرم، حداقل حجم، Stops Level، ساعات معاملاتی، پسوند نمادها)
بین بروکرها و حتی بین انواع حساب یک بروکر متفاوت است. تعمیم دادن یک عدد از یک بروکر به بروکر دیگر،
پاسخ غلط تولید می‌کند. به همین دلیل قاعده‌ی `MET-RULE-0005` هر رکورد بروکری را ملزم می‌کند به:

* `broker` — نام دقیق بروکر
* `validity` — تاریخ اعتبار، نوع حساب و منبع رسمی
* `source.source_type = BROKER_DOCUMENTATION`

## ورودی موردنیاز

1. نام بروکر یا بروکرهایی که دانشجویان آکادمی استفاده می‌کنند.
2. نوع حساب‌ها (Standard / ECN / Cent / بدون سواپ).
3. صفحه یا فایل رسمی مشخصات نمادها و شرایط معاملاتی (PDF یا اسکرین‌شات قابل استناد).
4. پسوند نمادها در پلتفرم (مثلاً `EURUSD.m`).

پاسخ به سؤال‌هایی مثل «اسپرد طلا چقدره؟» یا «حداقل حجم چنده؟» تا دریافت این اطلاعات
باید به «مشخصات نماد در پلتفرم خودتان» ارجاع داده شود، نه به عدد ثابت.
