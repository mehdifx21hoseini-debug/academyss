# ساختار پایگاه دانش

```
raw_sources/          منابع خام، دست‌نخورده و بایگانی‌شده
knowledge_base/       دانش ساختاریافته (هر فایل JSON = یک «مجموعه»)
    academy/          دانش آکادمی: دوره‌ها، متدولوژی، قواعد، کاتالوگ، واژه‌نامه
    mentor_qa/        raw → cleaned → structured → approved
    metatrader/       mt4/ · mt5/ · comparison/ · عیب‌یابی مشترک
    brokers/          دانش وابسته به بروکر (هر رکورد با نام بروکر و تاریخ اعتبار)
    general_trading/  دانش عمومی + قرنطینه‌ی روش‌های بیرونی
    psychology/       الگوهای روان‌شناسی معامله‌گری
    conflicts/        دفتر ثبت تعارض‌ها
    review_queue/     مواردی که به تصمیم انسانی نیاز دارند
schemas/              اسکیما و واژگان کنترل‌شده
tools/                خط پردازش (پایتون بدون وابستگی + یک اسکریپت Node)
manifests/            مانیفست اصلی پایگاه دانش
reports/              گزارش‌های اعتبارسنجی
exports/              خروجی نهایی نسخه‌دار (Markdown / JSON / CSV)
```

## قواعد کوتاه

1. فایل خام هرگز ویرایش نمی‌شود.
2. هر شیء دانش باید منبع و محل دقیق آن را داشته باشد.
3. محتوای بدون منبع بیرونی → `MODEL_DRAFT` + `verification_required = true` و هرگز `APPROVED` نمی‌شود.
4. متدولوژی آکادمی هرگز با دانش عمومی یا روش‌های بیرونی مخلوط نمی‌شود.
5. تعارض‌ها حذف نمی‌شوند؛ ثبت می‌شوند و منتظر تصمیم انسانی می‌مانند.
6. خروجی‌ها نسخه‌دار هستند و بازنویسی نمی‌شوند.
