SS REPLAY - نصب و کامپایل
=========================================================

مهم: شما در MetaEditor هیچ کدی نمی‌نویسید و هیچ Expert جدیدی
نمی‌سازید. این پروژه ۱۰۱ فایل است. فقط پوشه‌ها را کپی می‌کنید.

---------------------------------------------------------
گام ۱ - پوشه‌ی داده‌ی متاتریدر را پیدا کنید
---------------------------------------------------------
در MetaTrader 5:   File  >  Open Data Folder
یک پنجره‌ی Explorer باز می‌شود. داخلش پوشه‌ی MQL5 هست.

---------------------------------------------------------
گام ۲ - کپی کنید
---------------------------------------------------------
از این ZIP، این ۵ پوشه را داخل همان MQL5 بریزید:

    Experts     ->  MQL5\Experts
    Include     ->  MQL5\Include
    Indicators  ->  MQL5\Indicators
    Scripts     ->  MQL5\Scripts
    Services    ->  MQL5\Services

ویندوز می‌پرسد "Merge?" یا "ادغام شود؟"  -> بله.
هیچ فایلی از خودتان پاک نمی‌شود؛ همه‌ی فایل‌های ما داخل
زیرپوشه‌ی SSReplay هستند.

---------------------------------------------------------
گام ۳ - کامپایل  (روش آسان و کامل)
---------------------------------------------------------
Command Prompt را باز کنید (کلید ویندوز، تایپ: cmd)
و این را بچسبانید - مسیرها را با مال خودتان عوض کنید:

"C:\Program Files\MetaTrader 5\metaeditor64.exe" /compile:"<مسیر MQL5>\Experts\SSReplay" /log:"%USERPROFILE%\Desktop\ssr1.log"
"C:\Program Files\MetaTrader 5\metaeditor64.exe" /compile:"<مسیر MQL5>\Scripts\SSReplay"  /log:"%USERPROFILE%\Desktop\ssr2.log"
"C:\Program Files\MetaTrader 5\metaeditor64.exe" /compile:"<مسیر MQL5>\Indicators\SSReplay" /log:"%USERPROFILE%\Desktop\ssr3.log"
"C:\Program Files\MetaTrader 5\metaeditor64.exe" /compile:"<مسیر MQL5>\Services\SSReplay" /log:"%USERPROFILE%\Desktop\ssr4.log"

چهار فایل log روی Desktop ساخته می‌شود. همان‌ها را برایم بفرستید.

اگر پنجره‌ای باز شد و بسته شد - طبیعی است. log نوشته شده.

---------------------------------------------------------
گام ۳ (جایگزین) - کامپایل دستی در MetaEditor
---------------------------------------------------------
اگر روش بالا کار نکرد:

۱. MetaEditor را باز کنید (از متاتریدر: Tools > MetaQuotes Language Editor)
۲. در پنل Navigator سمت چپ، پوشه‌ی SSReplay را پیدا کنید
۳. این فایل را دوبار کلیک کنید تا باز شود:
       Experts\SSReplay\SSReplayStandalone.mq5
۴. کلید F7 را بزنید
۵. پایین پنجره، تب Errors را نگاه کنید

این یک فایل تقریباً همه‌ی ۶۶ فایل Include را می‌کشد، پس اگر
این کامپایل شود، بیشتر پروژه سالم است.

بعد همین کار را برای این فایل هم بکنید:
       Scripts\SSReplay\QA\SSR_QA_Preflight.mq5

---------------------------------------------------------
گام ۴ - چه چیزی برایم بفرستید
---------------------------------------------------------
هر خطی که در تب Errors یا در فایل log هست. عیناً. مثل این:

    'X' - some error text    SSR_Panel.mqh    142    17

فایل، شماره‌ی خط، شماره‌ی ستون، متن. خلاصه نکنید.
حتی اگر صد خط بود.

اگر نوشت "0 errors, 0 warnings" - همین را بگویید. عالی است.

---------------------------------------------------------
گام ۵ - فقط بعد از اینکه کامپایل سبز شد
---------------------------------------------------------
در متاتریدر، تب Navigator > Scripts > SSReplay > QA
فایل SSR_QA_Preflight را روی یک چارت بکشید.
خروجی در تب Experts چاپ می‌شود. آن را هم برایم بفرستید.

هنوز SSReplayStandalone را اجرا نکنید. اول کامپایل، بعد
Preflight، بعد بقیه.
