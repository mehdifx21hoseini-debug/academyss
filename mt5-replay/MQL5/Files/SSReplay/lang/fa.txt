# SS Replay - Persian / فارسی
#
# One line per string:   name = text
#
# Lines that are blank, start with #, or name something this build does
# not have are SKIPPED. A missing line falls back to English, so a
# partial translation is usable - you can ship sixty of these and the
# rest simply stays in English.
#
# WHAT NOT TO TOUCH: the %d, %s, %.2f and %% markers. They are where a
# number is inserted, they must stay, and they must stay IN THE SAME
# ORDER as the English line. A line with the wrong markers will print
# the wrong number, or nothing.
#
# Digits stay Latin on purpose: the panel uses Tahoma because it draws
# all ten digits on the same width, which is what keeps a price column
# lined up. Persian digits break that.
